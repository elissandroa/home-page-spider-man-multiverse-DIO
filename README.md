# 🕸️ Home Page Spider-Man: Multiverse - DIO

Bem-vindo(a) ao universo de possibilidades do Homem-Aranha! Este projeto é uma landing page inspirada no multiverso do Spider-Man, desenvolvida como parte do bootcamp da Digital Innovation One (DIO). Explore, inspire-se e veja como a criatividade, atenção aos detalhes e habilidades técnicas se unem neste universo digital!

## 🚀 Sobre o Projeto

O objetivo principal deste projeto é demonstrar habilidades em **HTML**, **CSS** e **JavaScript**, criando uma página inicial visualmente impactante e interativa, que celebra diferentes versões do Homem-Aranha através dos multiversos.

## ✨ Funcionalidades

- Design responsivo inspirado no universo Spider-Man
- Seções destacando diferentes Aranhas do multiverso
- Animações e efeitos visuais modernos
- Navegação fluida e intuitiva
- Código limpo, semântico e pronto para manutenção

## 🧩 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica e acessível
- **CSS3**: Estilização avançada, animações e responsividade
- **JavaScript**: Interatividade e dinamicidade na página

## 🎯 Diferenciais

- Layout pensado para causar impacto visual imediato
- Uso de paleta de cores e fontes temáticas do universo Spider-Man
- Atenção especial à experiência do usuário (UX/UI)
- Código comentado e organizado, facilitando a colaboração e manutenção

## 💡 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/elissandroa/home-page-spider-man-multiverse-DIO.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd home-page-spider-man-multiverse-DIO
   ```
3. Abra o arquivo `index.html` em seu navegador favorito.
